# Design Resources & Component Combinations Registry

This folder contains the complete, curated **Top 100 Combinations of Hero Pages, Scroll Animations, and Button Animations** sourced from [21st.dev](https://21st.dev/), Aceternity UI, Magic UI, Motion Primitives, and Kokonut UI.

## Markdown & Resource Files

1. [top-100-combinations-links.md](file:///b:/new/files/top-100-combinations-links.md)
   - **Dedicated Links Directory:** Fast lookup list for every single combination with direct links to 21st.dev and official documentation.
2. [top-100-hero-scroll-button-combinations.md](file:///b:/new/files/top-100-hero-scroll-button-combinations.md)
   - **Comprehensive Master Guide:** 100-row master directory table, full UX synergy breakdowns, motion physics formulas, and code tokens.
3. [top-100-combinations-database.json](file:///b:/new/files/top-100-combinations-database.json)
   - **Machine-Readable Database:** Complete JSON schema with component links, authors, categories, and technical styling tokens.
4. [combinations-catalog.html](file:///b:/new/files/combinations-catalog.html)
   - **Interactive Visual Dashboard:** Searchable and filterable UI card dashboard for previewing all 100 combinations in any browser.
