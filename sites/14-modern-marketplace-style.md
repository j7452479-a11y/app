# Genre 14: Modern Marketplace Style

**Target Segment:** Multi-brand retailers, department stores, horizontal ecommerce portals, resale marketplaces, mega catalog networks.  
**Key Architectural Traits:**
- **Dense Navigation:** Multi-level mega menus with department trees, brand directories (A-Z indexes), quick category icon bars.
- **Search-Focused Homepage:** Centrally dominant search input with instant autocomplete suggestions, recent search history, trending search tags, voice search triggers.
- **Promotional Zones:** Countdown flash-sale ribbons, hero carousel banners with multiple promo slides, category discount callouts (e.g. "Up to 50% Off Outerwear").
- **Product Collections:** Curated collection carousels ("Trending Now", "Editor's Picks", "New Arrivals This Week", "Staff Favorites", "Under $50").
- **Advanced Filtering:** Multi-faceted filter drawers (Price range sliders, Brands multi-select, Customer ratings, Delivery speed / Prime filter, Color swatches, Size pills, Discount percentage).
