# Genre 04: Electronics Grid

**Target Segment:** Consumer electronics, computer hardware, audio equipment, gaming peripherals, smart home, photography gear.  
**Key Architectural Traits:**
- **Specification-Heavy Cards:** Dimension callouts, chipsets/sensors, wattage/battery life, connectivity standards (Bluetooth 5.3, Wi-Fi 7, USB-C PD), weight.
- **Comparison Sections:** Multi-product side-by-side spec comparison matrices with sticky header rows and highlighted differentiator rows.
- **Filters:** Deep faceted filtering (processor, RAM, resolution, form-factor, socket, wireless vs wired, frequency response).
- **Warranty Information:** Manufacturer warranty badges (1-Year, 2-Year, 3-Year), optional extended protection plans (AppleCare+, Asurion, SquareTrade), return period guarantees.
- **Stock Indicators:** Real-time stock status pill badges ("In Stock - Ships Today", "Only 3 Units Left", "Backordered: ETA Nov 12", "Discontinued").
