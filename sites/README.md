# Top 50 Benchmark Sites Across 14 Commerce & Service Genres

This repository directory contains curated, industry-leading **TOP 50 reference websites** for each of the 14 commerce and service genres defined below. Each site is audited against the genre's distinct UX, UI architecture, feature set, and interaction patterns.

Total: **700 curated benchmark websites** across 14 genres (50 per genre).
